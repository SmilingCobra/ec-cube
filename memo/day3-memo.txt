4. データベースのテーブルとフィールド
   4.1 新しいフィールドを足す：
   - 新しい trait を使う
   @ORM\Column(name = "production_area", type = "string", length = 255, nullable = true)
   - クラスに書く：
   use \Customize\Entity\ProductTrait;
   - コンテナでコマンド：
   bin/console cache:clear --no-warmup
   bin/console doctrine:schema:update --dump-sql --complete
   bin/console doctrine:schema:update --dump-sql --force --complete
   4.2 新しいテーブルを作る：
   - クラスを書く：class WebdocNews extends AbstractEntity
   - コンテナで同じコマンドを使う

5. フォームデータを受けると渡す
   5.1 フォームデータを受ける：
   $builder = $this->formFactory->createNamedBuilder('', CustomizeProductNameType::class);
   $nameForm = $builder->getForm();
   $nameForm->handleRequest($request);
   if ($nameForm->isSubmitted() && $nameForm->isValid()) {
       $status = 'success';
   }
   5.2 フォームデータを作る：
   public function buildForm(FormBuilderInterface $builder, array $options){
       $CustomizeProducts = $this->customizeProductRepository->customFindAll();
       $choices = [];
       foreach($CustomizeProducts as $CustomizeProduct){
           $choices[$CustomizeProduct->getName()] = $CustomizeProduct->getName();
       }
       $builder->add('product_name', ChoiceType::class, ['choices' => $choices]);
       $builder->add('submit', SubmitType::class, ['label'=> '表示する']);
   }
