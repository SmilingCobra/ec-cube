第一日　メモ

1.ec-cubeのインストール
	1.1 コードのアドレス
		https://github.com/EC-CUBE/ec-cube
	1.2インストールのステップ
		git clone https://github.com/EC-CUBE/ec-cube
		cd path/to/ec-cube
		PostgreSQLをデータベースとして選び、Dockerで起動します。
		docker-compose -f docker-compose.yml -f docker-compose.pgsql.yml up -d
		でデータベースのテーブルを初期化します。
		docker-compose -f docker-compose.yml -f docker-compose.pgsql.yml exec ec-cube composer run-script compile
	1.3機能の確認：
		会員登録を行い、個人情報を入力した後、localhost:1080 でメールを確認してアカウントを有効化します。その後、正常にログインできます。
	1.4主な URL 情報:
		localhost:8080: ショップ画面
		localhost:8080/admin: 管理画面
		localhost:1080: メールを見る画面(schickling/mailcatcher:latest)

2.ec-cubeの管理画面のメニュー
	2.1 商品管理
		2.1.1 商品情報登録
		商品の基本情報を登録します。
		2.1.2 規格管理
		商品ごとに選べる オプションを設定します。例：サイズ、味など。
		2.1.2 カテゴリ管理
		2.1.3 タグ管理
		その他の属性の説明
	2.2 受注管理 ＆　会員管理
	2.3 コンテンツ管理
	　　コンポーネントを移動したり、フロントエンドのコードを変更して、ページの表示を変えます。
